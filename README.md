# WordBloom

WordBloom is a playful picture-word learning website designed to help young students build confidence with everyday English vocabulary.

Students see a clear picture, read the word and a short example sentence, and hear gentle automatic pronunciation. Each lesson stays on the current card until the student presses the large **Next Word** button, giving them plenty of time to listen and repeat.

## Features

- 1,200 illustrated vocabulary practice cards
- Gentle automatic pronunciation for each new card
- Simple example sentences such as “This is a pen.”
- Distraction-free learning mode
- Large, child-friendly next-word navigation
- Food, animals, school, objects, places, and nature categories
- Search and category filters
- Saved learning progress on the student's device
- Responsive layout for computers, tablets, and phones

## How to use

1. Open WordBloom and select **Start Learning**.
2. Look at the picture while the word and sentence are spoken.
3. Repeat the word aloud.
4. Press **Next Word** when ready to continue.

## Local development

This project uses Next.js, React, TypeScript, and Vinext.

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser.

## Production build

```bash
npm run build
```

## Accessibility

WordBloom uses large controls, clear color contrast, descriptive labels, responsive layouts, and native browser speech synthesis. Available voices can vary by browser and operating system.
